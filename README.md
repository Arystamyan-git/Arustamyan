# Экзаменационный проект «Детский мир»

Готовый WordPress-магазин для билета №3. Основной адрес из дампа: `http://mysite5.rus`.

## Запуск

1. Создать MySQL-базу `kid_world` и импортировать `kid_world.sql`.
2. Настроить веб-сервер с корнем в папке `wordpress` и доменом `mysite5.rus`.
3. При необходимости добавить `127.0.0.1 mysite5.rus` в файл hosts.
4. Проверить реквизиты MySQL в `wordpress/wp-config.php`.
5. Открыть сайт. При первом запросе тема автоматически создаст категории и товары из обязательных медиафайлов.

Администрирование: `http://mysite5.rus/wp-admin/`, логин `Admin`, пароль `giveme5`.

## Реализовано

- отдельная адаптивная тема `detmir-exam`;
- WooCommerce: 6 категорий, 18 товаров, наличие, цены, корзина и оформление заказа;
- не более 4 товаров на странице и пагинация;
- закреплённое меню, главная, каталог, блок о компании, контакты;
- форма «Напишите нам» с требуемыми полями; обращения сохраняются в админ-панели;
- политика использования из материалов;
- социальные ссылки через отдельный плагин;
- плагин Google Analytics с идентификатором `UA-333438812-2`;
- обязательные изображения и текст из `Медиа3.zip`.
